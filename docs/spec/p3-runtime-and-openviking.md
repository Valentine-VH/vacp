# P3 · 真实运行时与 OpenViking 接入规格

状态：待实施。依赖 [P0 宿主验证](p0-runtime-host-checklist.md)、[P1 节点与任务协议](p1-node-task-protocol.md) 和 [P2 技能绑定](p2-skill-import-and-binding.md)。主演示由真实 DSH 发起委派、真实 OpenCode 执行，OpenViking 为检索后端。Vector Agent 的 Milvus 链路保留独立适配边界。

DSH 与 OpenCode 插件使用 VACP 的节点身份下载已审核的技能，按版本摘要验证后再加载。联调要求见 [技能安全审核与插件分发](skill-review-and-distribution.md)。

## 执行链路

1. Web 用户向获授权的 DSH Agent 提交根任务。DSH Connector 从已验证的宿主入口启动或关联独立会话，工具调用使用当前 Attempt 的身份向 VACP 提交委派。
2. VACP 复核发起用户、父任务租约、目标 OpenCode、委派允许列表与资源引用。派发给 OpenCode 的输入包含必要摘要和获授权引用。技能固定版本按 P2 解析。
3. OpenCode Connector 使用 P0 验证过的入口启动隔离会话并关联 Attempt。OpenCode 调用受控知识检索工具时，VACP 服务端校验并调用 OpenViking，再返回有界结果和平台引用 ID。
4. OpenCode 回报结果及引用给 VACP，DSH 读取经授权的子任务结果并汇总。Web 展示执行步骤、最终输出和来源。DSH 与 OpenCode 分别保留原始会话，VACP 记录节点、运行时版本与宿主会话引用。

## 知识库配置、授权和引用

- Owner 或 Admin 配置 OpenViking 连接、知识范围和 Agent 绑定。连接凭据通过服务端密钥引用取得。连接测试检查连通性，试搜以指定 Agent 和当前用户的授权范围执行检索。P3 以预置的测试知识范围为边界验证适配器接口及实际版本。
- 实际检索授权取工作空间成员权限、用户资源授权、Agent 知识库绑定和任务执行范围的交集。每次请求解析真实节点、连接代次、Attempt 和租约，禁止用客户端传入的空间、用户或知识范围作为授权依据。
- 适配器向 OpenViking 传递服务端解析的检索范围，并在返回前复核来源归属。后端连接限定配置的 HTTPS 入口，开发环境按环境约定显式启用本地连接。试搜或连接测试错误仅返回脱敏状态。
- 结果包含受控摘录、来源名称、上游定位信息和平台引用 ID。Web 打开引用时重新校验资源权限，撤销后禁止读取原文。任务终态保留审计所需的历史元数据。若既有答复保留了摘录，须按任务权限和数据保留规则处理，引用撤销不会自动回收已展示的文本。
- 适配器按有限超时、结果条数与响应大小控制检索。知识库内容按数据处理，无法改变授权、工具能力或委派目标。

## 文件记忆

默认关闭。允许 Owner 或 Admin 对 Agent 开启，运行时以执行节点上的工作空间、用户及 Agent 配置划分目录。测试必须能验证实际读写隔离。对用户可控路径、符号链接或绕出目录的访问拒绝。授权撤销后，平台拒绝后续记忆访问并触发 P1 的任务取消流程。原节点保存文件，跨节点迁移、共享会话和全局记忆留在后续范围。

## 失败、重连和取消

| 情况 | 行为 |
|---|---|
| 宿主入口不兼容或能力未验证 | 标记该能力不可用，控制台显示宿主版本与阶段。真实接收不可用时，记录 P3 阻塞 |
| OpenViking 无结果、超时、鉴权失败 | 分别报告无匹配、暂时不可用和配置问题。允许有限重试只读检索。要求知识依据的任务在检索失败时返回明确的受限结果或失败状态 |
| 节点断线、租约失效 | 按 P1 重连和补报。同一 Attempt 可恢复时关联原宿主会话。不能确认是否已执行时标记结果未知，禁止自动创建新会话重跑 |
| 知识库授权、技能绑定或节点凭据在运行时撤销 | 服务端拒绝后续访问。必需资源不可用时报告原因，按 P1 取消或终结受影响任务。已有副作用不由平台宣称回滚 |
| 用户取消或完成先到 | Connector 使用 P0 已验证的取消入口。宿主确认停止后才回报取消成功。已提交的有效终态保持一致，无法确认时记录结果未知 |
| 引用丢失、超出授权范围或无法定位 | 拒绝生成可打开的引用。对错误范围记录审计，客户端显示来源不可用 |

## 验收步骤

| 编号 | 操作与预期 |
|---|---|
| R01 真实会话 | 用主空间成员向 DSH 发起一条文本任务，再由真实工具委派给 OpenCode。记录宿主版本、两端会话 ID 和父子任务 ID |
| R02 技能与检索 | 给 OpenCode 绑定 P2 固定版本和一个 OpenViking 测试知识范围，执行资料核对。记录技能摘要、实际检索证据和返回的引用。Web 打开引用能定位到授权资料 |
| R03 权限 | 以隔离空间节点、未绑定知识库的 Agent 和已撤销成员分别请求同一资料、任务或引用。全部拒绝，越权请求不触达上游 |
| R04 故障 | 分别触发空结果、后端超时与无效凭据。控制台能区分。恢复后可检索，失败期间不产生虚构引用 |
| R05 断线与取消 | 运行期间断开 OpenCode Connector 再恢复，另发一条可取消任务。验证任务事件可补报、不会重复启动，取消语义与宿主实测一致 |
| R06 文件记忆 | 同一用户、空间、Agent 在两次独立任务间读到已有文件。换用户或空间后无法读取。关闭记忆后任务不再访问该目录 |

通过条件为真实宿主的父子任务、授权检索引用和结果可以关联复现，权限与故障检查有记录。Mock 路径只作为回归基线。
