# P2 · 技能导入与 Agent 绑定规格

状态：待实施。现有 SkillHub / ClawHub 目录、空间技能仓库和内部市场安装作为基线。P2 补齐外部文档进入私有仓库、固定版本安装、绑定到 Agent 以及执行时读取的链路。

导入确认后须通过 Scanner 与人工审核，批准后才能安装、绑定或下载。节点分发与撤销规则见 [技能安全审核与插件分发](skill-review-and-distribution.md)。

## 入口与权限

| 操作 | 授权与范围 |
|---|---|
| 搜索外部市场、打开来源 | 当前工作空间成员。目录结果沿用上游可见范围 |
| 预览待导入的外部内容、确认导入 | 当前空间 Owner 或 Admin。确认前展示来源、作者、精确版本、许可状态和实际导入内容 |
| 安装、卸载、绑定或解绑 | 当前空间 Owner 或 Admin。目标 Agent 和安装记录必须属于同一空间 |
| 查看私有仓库、安装及绑定 | 按当前空间的读权限，跨空间不可发现。外部导入进入私有库，发布需要独立操作与明确的再分发许可 |
| 执行时读取文档 | 有效节点凭据、连接代次和 Attempt 租约均须匹配。读取范围限当前 Agent 已绑定、任务已引用且仍获授权的精确版本 |

导入、安装、绑定和公开发布分别授权。用户可在「技能市场 → 来源详情 → 导入预览」确认来源，再从「已安装」或 Agent 详情绑定。审计记录操作者、技能版本、目标 Agent 和动作结果，避免写入原文及上游凭据。

## 导入、版本和生命周期

1. 从选定的 SkillHub 或 ClawHub 条目解析稳定来源坐标和精确版本。服务端适配器使用预配置的上游地址，按已验证的上游接口读取。目录有结果与资源可以导入是两个独立状态。
2. 只接收可验证来源的文档型技能。遇到付费、登录、权限不足、来源发生跳转或许可不允许当前用途时，给出原因及来源入口。包内程序、依赖和安装指令留作原文说明。若上游用压缩包提供文档，只在受限读取中提取所需文档，校验类型、路径和扩展后大小。
3. 预览返回短期导入标识，关联空间、操作者、来源、版本、许可状态和内容摘要。确认时核对标识、上游版本和摘要，内容变化要求重新预览。只将用户确认过的内容保存为不可变快照。
4. 私有快照保存来源、上游坐标及 URL、上游版本、文档摘要、许可信息、导入人与时间。相同空间重复确认同一快照返回原记录。相同上游版本出现不同内容时显示冲突，进入重新预览与审查。
5. 安装记录固定指向一个快照版本，Agent 绑定指向该空间的安装记录。支持并行保留多个版本。Agent 对同一来源技能选择一个有效版本；切换版本需要显式确认。修改本地副本生成独立修订并保留来源链。升级、编辑或重新导入均不改变现有绑定。
6. 任务派发时固定技能版本清单与摘要。新绑定或升级用于新任务。解绑、卸载或授权撤销后，拒绝后续读取。卸载已绑定版本返回冲突并列出相关 Agent，先解绑或切换版本。运行时仅在授权范围内读取文档并校验摘要。

## 失败处理

| 情况 | 行为 |
|---|---|
| 上游超时、限流、下载失败 | 区分来源不可用与搜索无结果。允许重试，现有仓库和绑定保持可用 |
| 上游不提供固定版本、许可无法确认、内容超限或类型不受支持 | 拒绝确认导入，展示具体原因和来源详情 |
| 预览过期、摘要变化、两个操作并发确认 | 过期或变化要求重新预览。重复确认复用同一已导入记录。数据库写入保持原子性 |
| 无权访问、目标不在当前空间、节点已撤销 | 与 P1 的 401/403/404 一致。拒绝创建、绑定或读取 |
| 任务需要的已固定技能不可用 | 明确报告版本、授权或完整性错误，禁止静默换成其他版本。根据任务配置终止或显式降级 |

## 验收步骤

| 编号 | 操作与预期 |
|---|---|
| S01 来源 | 在两个来源搜索并查看详情。至少从一个来源真实导入一个固定版本，记录来源、许可状态和摘要。另一来源若不可导入，验证原因及来源跳转 |
| S02 安装与绑定 | 管理员从预览确认、安装并绑定到 A。A 的 Mock Attempt 读取并校验文档摘要。同一空间未绑定的 B 无法以自己的 Attempt 读取 |
| S03 版本 | 导入后编辑本地副本或导入新版本，旧绑定仍解析原快照。手动切换后才变化，未确认的改动不出现在运行时 |
| S04 隔离 | Viewer 不能导入、安装或绑定，隔离空间不能读取私有快照。解绑后新任务不获得该版本，旧任务后续读取按撤销规则拒绝 |
| S05 故障与重放 | 模拟上游超时、预览内容变化及重复确认。验证失败不产生半成品、重试不重复创建、旧绑定仍可用 |

P2 用 Mock Attempt 证实技能版本确实送到目标节点。真实 OpenCode 使用同一条绑定链路，由 P3 验收。
