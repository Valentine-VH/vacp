## Web 任务工作台

| 界面 | 交互 |
|---|---|
| 任务列表 | 顶部显示当前工作空间。列表按状态和 Agent 筛选，保留筛选条件。选择一条任务打开详情，链接包含工作空间和任务 ID。切换工作空间清理上一个空间的任务选择、详情、缓存与订阅 |
| 发起任务 | Ant Design X 的 Sender 接收文本。预选有权限且在线的默认 Agent，允许换成其他可用 Agent。默认 Agent 离线或已撤销时显示原因，要求换选。发送期间保留草稿并防止重复提交，服务端确认后清空并打开详情 |
| 任务详情 | Bubble 展示用户输入和最终输出。执行过程展示排队、Agent 分工、工具调用与父子任务关系，支持展开详情。运行时明确提供的可展示摘要按需单列。父子任务能双向跳转 |
| 结果与来源 | 引用显示来源和摘录，点击由服务端重新授权后打开。产物显示名称和大小，通过受授权入口下载。无引用或产物时按实际结果显示 |
| 取消与重试 | 有权限且任务可取消时才显示取消操作。待执行可直接取消，等待宿主停止时显示「取消中」。重试只在服务端认定可安全重放时开放，并保留与原任务的关联 |

详情先加载持久化快照及其事件游标，再订阅该游标之后的 SSE。事件按任务 ID 和序号去重，发现缺口先补读再继续。断线保留已确认的内容并显示重连状态。切换任务或工作空间时终止旧连接，忽略迟到的响应。任务终态以服务端记录为准。任务正文、日志、引用与第三方输出按不可信内容渲染。

## uni-app H5

提供登录、工作空间切换、任务列表和任务详情。移动端用卡片展示任务名称、目标 Agent 和状态。详情展示父子关系、时间线、最终输出及可访问引用。返回列表保留当前空间和筛选状态，浏览器直接打开任务链接时先检查登录及资源权限。

H5 首版只读，与 Web 使用相同的工作空间授权和任务接口。使用共享 API 契约，通过 H5 适配层处理会话过期和网络状态。活动任务在页面可见时按有限频率轮询，页面隐藏、切换或收到终态后停止。恢复可见时立即刷新。手动刷新保留当前任务，网络失败时已确认的结果标为可能过期。Web 和 H5 均应读到同一任务 ID、终态和输出。

## 异常与恢复

| 情况 | 页面反馈及动作 |
|---|---|
| 列表为空、筛选无结果、读取失败 | 分别展示空状态、清除筛选、重试。读取失败时明确标注已有数据的状态 |
| 提交超时或连接中断 | 保留草稿和同一次提交的幂等键。重试或查回执时复用该键，找到原任务后打开详情 |
| 默认 Agent 不可用或派发失败 | 在发送区显示明确原因与可用替代项。服务端已创建任务时，在任务详情展示最终状态和可用操作 |
| SSE 断线、事件重复或缺号 | 提示重连，从最后确认序号补读。重复事件不重复展示，缺号时从持久接口恢复 |
| 取消与完成并发、宿主未确认停止 | 显示服务端最终结果。完成先提交时保留结果，未确认停止则显示结果未知，并区分发出取消请求和确认停止 |
| 登录失效、成员权限撤销或切换空间 | 停止请求和订阅，清理相关数据。登录失效回到登录页，资源不可访问返回任务列表或当前可用空间，避免残留旧内容 |
| 引用撤销、检索失败或无资料 | 显示来源不可用、检索失败或无匹配，分别提示可重试项。已获授权的其他内容仍可查看 |

## 完整演示手册

1. 固定并记录 VACP、DSH、OpenCode 和 OpenViking 版本。准备同源 Web/H5 访问入口、可用模型配置、测试连接说明、可导入的文档型技能版本和一份有唯一可核查段落的发布说明。凭据通过环境或密钥存储配置。
2. 从空白主工作空间开始，创建 Owner、Member 及一个隔离空间账号。用 Owner 登记两个真实节点，确认在线、运行时类型和能力正确。将 DSH 设为默认 Agent，并授权它委派给 OpenCode。
3. 在市场预览来源与版本，导入并安装该技能，绑定给 OpenCode。添加 OpenViking 知识范围，用同一 Agent 试搜确认返回正确来源。
4. 用 Member 登录 Web，提交「根据发布说明起草客户答复」。确认 DSH 创建真实会话并委派，OpenCode 使用绑定技能检索资料，结果含可打开引用。检查父子任务、两个宿主会话与最终答复相互对应。
5. 用同一 Member 登录 uni-app H5，切到主空间打开该任务，对比任务 ID、终态和输出。退出后改用隔离空间账号，验证原链接、任务 API 和来源入口均受限。
6. 用独立样例复测断线恢复、节点离线、取消和后端故障。每次保存任务 ID、最后事件序号、期望与实际结果。最终复跑一次正向流程，确认恢复后的环境可用。

## 端到端验收

| 编号 | 执行与通过条件 |
|---|---|
| E01 正向交付 | Edge 或 Chrome 从空工作空间重复手册 1–4。记录两端真实会话、技能版本及摘要、检索来源、父子任务 ID 和最终输出 |
| E02 H5 一致性 | 在窄视口 H5 验证登录、切换空间、任务详情及刷新。与 Web 核对同一记录，活动任务结束后停止轮询 |
| E03 Web 断线 | 任务运行时断开 Web，恢复后验证事件顺序与持久记录一致。切换任务再返回、刷新或重启服务，确认无重复执行步骤且结果可重读 |
| E04 取消 | 分别测试排队取消和真实宿主运行中取消，再测试完成先到。状态与 P1/P3 一致，保留取消前历史，父任务取消传播至活跃子任务 |
| E05 权限 | 隔离空间直接请求任务、SSE、引用和产物。撤销主空间成员后重复并检查已打开的 Web/H5 页面停止读取、清理受限内容 |
| E06 故障 | 模拟提交响应丢失、连接超时及检索不可用。原任务不重复创建，错误可区分，恢复后新任务可以完成 |
| E07 可复现 | 另一个操作者仅按手册从干净测试空间完成主流程。保存脱敏日志、版本矩阵和验收记录，记录任何需要人工配置的步骤 |

P4 通过要求 E01–E07 有可复现证据。Mock 测试记录单独归档。真实节点、OpenViking 或取消行为缺少证据的条目标记阻塞或待验证。
