# 工作空间治理阶段

本阶段完成工作空间创建、成员角色管理和所有权交接。所有者可以将空间交接给同一空间内的现有成员。交接后原所有者成为管理员，新所有者获得交接和管理员管理权限。界面在确认前显示双方角色变化。

交接使用独立接口 `POST /api/v1/workspaces/:id/ownership-transfer`，请求提供接收人的邮箱。接口要求当前所有者身份，并与成员写入共用同一个工作空间行锁。数据库在同一事务中更新双方角色和写入审计记录。记录保存工作空间、发起人、接收人和交接时间。

所有者和管理员可查看最近 50 条交接记录。列表按交接时间倒序显示原所有者、新所有者和时间。查询接口为 `GET /api/v1/workspaces/:id/ownership-transfers`。已加入空间但无审计权限的成员收到 403，空间外用户收到 404。

- 第一阶段更新权限模型和持久层。
- 第二阶段在成员表接入交接入口、确认弹窗和结果反馈。
- 验收验证非成员与非所有者不可交接、交接后权限立即更新、同一个所有者并发提交仅一次成功，以及审计与角色一致。
