# VACP 愿景 PoC 实施计划

本计划定义 VACP 第一次完整演示的交付范围。技术边界沿用 [身份与架构规格](identity-architecture.md)，节点接入沿用 [DSH 插件规格](dsh-plugin.md)。当启动稿的阶段描述与本计划不一致时，愿景 PoC 的实施顺序和验收以本计划为准。

## 最终演示

工作空间所有者创建「产品支持」空间，邀请一名成员，登记 DSH 和 OpenCode 两个节点。所有者在技能市场查找并审核一个文档型技能，将固定版本安装并绑定到接收端 Agent，再给该 Agent 开通一份 OpenViking 知识库的读取权限。

成员在 Web 创建「根据发布说明起草客户答复」任务。任务先进入真实 DSH 会话。DSH 通过 VACP 工具把资料核对委派给 OpenCode。OpenCode 使用已绑定技能检索授权知识，返回带来源的核对结果。DSH 汇总最终答复。Web 通过 Ant Design X 展示执行步骤、引用来源和输出。刷新页面可以继续读取任务进度，uni-app H5 可以登录并查看同一个任务及结果。

演示另准备一个隔离工作空间。使用该空间的用户或节点访问「产品支持」任务、产物或知识库时，服务端拒绝请求并记录安全事件。

## 当前基线

| 模块 | 已有证据 | 愿景 PoC 缺口 |
|---|---|---|
| 账户与空间 | React 管理台、角色、成员管理、所有权交接与审计 | 将权限扩展到节点、任务、技能绑定和知识库 |
| 节点及任务 | 独立 Mock 进程可领取文本任务并回写 PostgreSQL | 正式注册和撤销、连接恢复、跨节点委派、事件流及取消 |
| 技能 | 自有仓库、固定发布快照、内部安装清单、SkillHub 与 ClawHub 实时目录 | 可审计的外部文档导入、版本锁定和运行时绑定 |
| 运行时 | DSH 与 OpenCode 的独立项目目录，已有 DSH 插件设计 | 实际宿主验证、版本矩阵、真实工具调用及任务接收入口 |
| 知识与记忆 | OpenViking、Vector Agent/Milvus 与文件记忆已有架构约定 | 接通受控知识检索、来源引用，验证文件记忆隔离 |
| Web / Mobile | React + Ant Design 管理台、uni-app H5 壳 | Ant Design X 任务会话和 uni-app H5 只读任务视图 |

## 用户功能与页面验收

Web 按「工作空间」「Agent」「技能」「知识库」「任务」组织入口。顶部统一选择工作空间。第一次进入空空间时，从 Agent 页的接入引导开始。Agent 验证在线后，管理员可进入详情配置能力，成员可在任务页选中已授权的 Agent 并发起验证。uni-app H5 覆盖登录、空间切换和任务查看。

| 功能 | 首版操作 | 验收 |
|---|---|---|
| Agent 管理 | 签发一次性接入凭据，复制接入指令，查看在线状态、宿主版本、能力和最近心跳，撤销节点 | 凭据只能兑换一次。节点重连沿用身份，离线状态会更新，撤销后不能重新连接或领取任务 |
| 工作空间默认 Agent | Owner 或 Admin 设置默认 Agent，任务表单预选，成员可改选有权限的 Agent | 默认 Agent 离线、被撤销或对当前用户不可用时，界面明确说明并要求重新选择 |
| Agent 能力配置 | 绑定技能固定版本和知识库，配置文件记忆开关和委派目标列表 | 配置保存后可回看。Agent 只使用显式绑定的技能与知识资源，委派目标同时受工作空间和服务端授权约束 |
| 技能仓库与市场 | 从 SkillHub 或 ClawHub 搜索，预览来源及版本，导入可用文档，安装后从 Agent 详情绑定 | 已导入项能回查来源及版本。不可导入项保留来源跳转并说明原因。新版本不会自动改变现有绑定 |
| 知识库管理 | 配置 OpenViking 连接，以指定 Agent 的授权范围试搜并查看引用 | 能区分连接异常、授权失败和无结果。试搜使用同一套授权规则，凭据由服务端保存 |
| 任务工作台 | 发送、查看进度与失败原因、取消、查看子任务和引用，下载任务返回的受控产物 | 父子任务可双向跳转。刷新后续读事件。跨空间直接访问任务、引用或产物被拒绝。重试只开放给已确认可安全重放的任务 |
| uni-app H5 | 登录、切换工作空间、查看任务状态和结果 | H5 与 Web 读取同一个持久化终态。撤销成员权限后，H5 后续请求同样被拒绝 |

管理动作默认由工作空间 Owner 和 Admin 执行。成员可向获授权 Agent 发任务并查看自己的任务及委派结果。只读角色按现有权限查看可读内容。界面提供加载、空列表、离线和失败反馈，权限以服务端校验为准。

[P4 任务工作台、H5 与愿景演示](p4-workbench-h5-demo.md) 定义 Web 与 H5 交互、异常恢复、从空工作空间开始的演示手册及最终端到端验收。

[技能安全审核与插件分发](skill-review-and-distribution.md) 是 P2 安装及分发验收的一部分。P3 验证 DSH 与 OpenCode 插件实际下载和加载。

P2 的扫描引擎、Vector 复用范围和部署方式见 [Skill Scanner 选型与部署](skill-scanner-selection.md)。

| 阶段 | 交付 | 通过条件 |
|---|---|---|
| **P0 运行时可行性** | 锁定 DSH 与 OpenCode 版本和 profile，验证工具注册、受控会话启动、输出事件和取消 | 两个宿主各完成一次真实工具调用。记录入口、宿主版本、取消实际语义和运行方式。DSH Desktop 与目标 CLI 若支持同一入口，使用同一 bundle 验证 |
| **P1 控制平面纵切** | 工作空间级 Enrollment、节点凭据、在线状态、撤销；PostgreSQL 任务、委派关系、Attempt、Outbox 和追加事件；WebSocket Connector、Web SSE | 两个独立 Mock 节点完成委派。断线重连保留节点身份。刷新补读有序事件。重复领取或回报只产出一次有效终态。撤销节点后拒绝新领取和结果回报 |
| **P2 技能从目录到执行** | SkillHub 或 ClawHub 选定版本导入到私有库，保留来源、版本、内容摘要和可用的许可证信息；市场按能力展示导入或来源跳转；按工作空间绑定技能到 Agent | 至少一个来源真实导入文档型技能。操作者预览并确认后安装，运行时可以读取该固定版本。修改本地副本后保留来源且不会回写上游。另一工作空间默认无法读取私有副本 |
| **P3 真实运行时和知识检索** | 真实 DSH 发起，真实 OpenCode 接收并执行。工作空间配置 OpenViking 知识库，通过服务端授权适配器检索，Agent 返回来源引用。File Memory 默认关闭，提供一次开启与隔离验证 | 同一任务记录能关联双方真实会话。输出包含可回查的已授权来源。另一个空间对同一知识库的调用被拒绝。开启记忆后，同一用户、空间和 Agent 配置可复用文件，其他用户或空间无权访问 |
| **P4 演示与交付** | Ant Design X 会话视图、uni-app H5 登录与任务查看、演示数据和运行手册 | 交付者按手册从空工作空间完成一次正向演示和权限拒绝、断线恢复、取消三条异常验证。Web 恢复事件后不重复显示执行步骤，H5 能读到同一终态 |

P0 与 P1 可并行启动。P0 先验证宿主实际提供的接口，避免后续围绕假设构建。若宿主暂缺稳定的接收接口，记录阻塞并验证受控桥接的可行性。只有实际运行时产出的结果才能计入 P3。Mock 可用于 P1 回归和临时演示，P3 仍标记待验收。

页面实施随对应能力交付。P1 先接 Agent 管理、默认 Agent 和任务工作台的 Mock 路径。P2 接技能导入、安装与绑定，P3 补知识库试搜、文件记忆开关及真实执行，P4 整理对话与 H5。每一阶段都从页面入口验收一条完整路径。

## 实现边界

- **任务和权限**。节点只能代表自己的工作空间。服务端校验发起身份、目标、资源引用和任务归属。委派有父任务 ID、目标 Agent、明确输入摘要和幂等键。自动重试限于可安全重放的操作；真实运行时的工具副作用需要独立确认策略。
- **技能**。外部来源的价格、许可、下载及内容形态以接口实际返回为准。导入用来源固定版本，首轮只转换可预览的文档内容。外部下载包内脚本、二进制和依赖安装留在独立能力评估范围。
- **会话与文件**。DSH、OpenCode 各自管理原始上下文。VACP 保存节点标识、会话引用、必要摘要、任务事件和经过授权的产物引用。长期记忆以工作空间、用户、Agent 配置划分文件目录。节点迁移和跨设备同步另行设计。
- **知识库**。主演示采用 OpenViking。Vector Agent 的 Milvus 链路保留独立检索适配边界，可作为后续对照验证，沿用现有索引并通过服务接口检索。
- **部署**。本地 PoC 使用 Node 26、PostgreSQL 和现有 React / uni-app 工程。Connector 作为独立进程。Web 和 API 可同源。PostgreSQL 是任务与事件的事实来源，首版沿用单实例调度。

## 验收记录

每个阶段记录运行版本、复现命令、输入、结果和限制。自动化回归覆盖权限、幂等、事件补读和租约。真实宿主测试记录实际节点及运行时版本、父子任务 ID、引用及终态。愿景 PoC 完成以最终演示、权限隔离和故障验证均通过为准。
