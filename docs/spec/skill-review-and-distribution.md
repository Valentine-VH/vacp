# P2 · 技能安全审核与插件分发

状态：待实施。此规格补充 [技能导入和绑定](p2-skill-import-and-binding.md) 与 [节点身份协议](p1-node-task-protocol.md)。

VACP Server 负责认证、授权和分发技能。DSH 与 OpenCode 的 VACP 插件使用同一套节点下载协议，获取可供各自宿主加载的已批准版本。插件自身通过各宿主的安装流程部署，作为注册节点的起点。

## 从导入到可安装

1. 管理员从 SkillHub 或 ClawHub 确认来源和版本后，服务端写入隔离快照，记录来源、许可、文件清单和 SHA-256。自有技能也在提交发布或请求安装时生成快照并进入同一审核流程。
2. 后台 Scanner 针对该快照运行。先校验文件类型、路径、体积与内容完整性，再检查文档中的可疑指令、敏感信息和异常权限要求。PoC 只允许文档型分发。程序、二进制、外部依赖和安装脚本不纳入可分发产物。
3. Scanner 输出结果、规则版本和脱敏问题摘要。通过扫描后进入人工审核。审核人员查看来源、实际分发内容和问题，确认允许的用途与范围后批准或驳回。
4. 只有「已批准」版本允许安装、绑定和下发。批准绑定到精确摘要、扫描规则版本和审核范围。内容变化、升级或本地改写产生新快照并重新扫描审核。工作空间内批准与公开发布分别授权，导入和私有批准不会自动公开。
5. 审计记录提交人、扫描结论、审核人、决策时间、理由、版本摘要和授权范围。审核记录与被审内容保持关联。

状态流转为「待扫描 → 扫描中 → 待审核 → 已批准 / 已驳回」。检测到禁止项转入「已阻断」，审核员不能覆盖强制阻断。扫描失败或超时进入「扫描失败」，可重试，保持不可安装。已批准版本可转入「已撤销」，撤销后须重新提交审核才能恢复。

## 审核权限

| 身份 | 操作 |
|---|---|
| 工作空间 Owner / Admin | 申请导入或提交自有技能，查看扫描和审核状态；管理已批准版本的安装与绑定 |
| 获授权的审核员 | 在授权工作空间审查、批准或驳回。正式流程要求提交人与批准人分离；PoC 若启用单管理员自审，须显式配置并标记审计 |
| 平台发布审核员 | 决定是否允许进入内部市场，并确认再分发许可及公开范围 |
| DSH / OpenCode 节点 | 仅下载当前 Agent 和有效任务获授权的已批准版本 |

## 节点下载

- 节点使用 P1 注册颁发的独立凭据。下载请求携带任务 Attempt 与该节点的运行授权。服务端核对凭据状态、节点与连接代次、租约、工作空间、Agent 绑定、任务固定版本和批准状态。
- 提议接口为 `GET /api/v1/connector/attempts/:id/skills` 及 `GET /api/v1/connector/attempts/:id/skills/:versionId/content`。清单包含来源、版本、文件清单、摘要及格式版本。内容经 HTTPS 由 VACP 授权下载。上游凭据仅留在 Server。
- 插件先写入临时位置，核对文件清单、路径和 SHA-256，再原子启用。失败时清理临时内容，任务返回明确的技能准备错误。PoC 由服务端直传文档，部署到对象存储时可再评估限定版本与有效期的下载凭据。
- 缓存限定到工作空间、节点、Agent 与版本摘要。每次任务加载前重新确认授权。技能撤销、解绑或节点撤销后，禁止新下载和新任务加载，在线节点停止使用并清理缓存。节点离线时无法即时回收已下载内容，重连后执行核对和清理。对已加载且依赖该技能的活跃任务发起取消，平台记录实际停止结果。

## Scanner 规则与结论

首版选型、Vector 代码迁入范围、Compose 部署和专项验收见 [Skill Scanner 选型与部署](skill-scanner-selection.md)。

对同一个规范化快照按顺序执行来源、结构、内容规则。结果至少含规则 ID、规则版本、严重度、文件与位置、脱敏摘要和机器判定。Scanner 运行于受限进程，限制时间、内存和文件输入，读取待审快照。扫描期间不执行文档中的命令、模板或包内脚本。

| 规则 | 判定与动作 |
|---|---|
| 来源和快照完整性 | 上游精确版本不可定位或摘要不符时终止提审。许可或再分发范围不明时标记待核实，相应用途无法批准 |
| 包结构 | 阻断路径越界、符号链接或特殊文件、加密条目、含大小写冲突的重复文件、目录冲突、超过上限的包，以及缺少、重复或格式无效的根 SKILL.md |
| 文档范围 | PoC 仅分发审查过的 UTF-8 文档。阻断可执行文件、依赖安装、嵌套压缩包及不支持的文件类型。分发摘要覆盖实际交付的完整文件清单 |
| 内容与数据 | 检出高置信度凭据时强制阻断。疑似凭据、要求提权、访问敏感目录、传输数据或覆盖上层约束的段落交人工判断。扫描报告只显示脱敏证据 |
| 扫描可用性 | 引擎超时、异常或报告格式错误时记为扫描失败，提供重试。规则发现风险时记录规则 ID；不得用空报告替代扫描成功 |

扫描通过代表可进入人工审核。批准时校验快照摘要、该次扫描结果和审核范围一致。新规则集如被标为强制复扫，受影响版本在复扫期间暂停新安装及下发；已有缓存按撤销策略处理。

## Web 审核页面

在「技能管理 → 审核」提供工作空间级队列和详情。队列支持按来源、版本、状态和风险筛选，显示提交人、提交时间、当前状态与需要采取的操作。只读用户按已有授权查看公开版本。审核队列与动作由服务端权限决定。

详情展示来源、许可状态、精确版本、待分发文件、摘要、扫描规则版本与问题位置。可切换查看上一个已批准版本的差异。文档按纯文本或经净化的 Markdown 渲染，避免执行主动内容。审核人可批准指定范围、驳回并填原因，扫描失败时可重试。强制阻断状态只显示原因和修正后重提的入口。

批准和撤销使用确认对话框，显示目标版本和受影响空间、绑定及运行任务。提交后以服务端回执更新状态。待审内容已变化或已被其他审核人处理时，显示冲突并重新加载详情。

## 版本撤销与插件失败处理

发布方获授权审核员可撤销其发布版本，平台审核员可撤销平台分发。消费空间 Owner/Admin 可移除本地授权或绑定，其影响限于当前空间。撤销记录理由和影响范围，保留审核记录与原版本摘要。服务端在撤销提交后拒绝新安装、绑定、清单授权和内容下载。正在传输的内容可能已到达节点，插件在启用前重新检查当前授权。在线节点接收撤销通知，离线节点重连后同步。已经执行的操作无法通过撤销回滚。

| 下载或启用失败 | DSH 与 OpenCode 共用处理 |
|---|---|
| 超时、断线、429 或临时 5xx | 有限重试，遵守服务端退避提示。每次重试都重新检查 Attempt 和版本授权；租约过期则停止 |
| 401、403、404 或版本撤销 | 停止重试该下载，重新注册或通过管理端修复授权。已撤销内容立即停止启用并清理本地可加载副本 |
| 文件缺失、摘要不符、路径异常 | 丢弃临时目录并上报完整性错误，下载内容不进入宿主加载目录。不可自动切换到其他版本 |
| 磁盘不足、原子启用失败、宿主加载失败 | 清理未完成的临时内容，报告失败阶段及可读原因，保留其他未受影响版本 |
| 必需技能无法启用 | 在宿主开始实际执行前失败。若运行中发现撤销，阻止继续访问并请求停止，最终结果以宿主确认和 P1 状态为准。可选技能是否允许降级由任务配置明确约定 |

插件向 Server 回报 `skill.download_failed` 或 `skill.load_failed`，附 taskId、attemptId、versionId、摘要、宿主、阶段、错误码和是否可重试。Web 工作台显示可操作反馈，日志不包含凭据、文档原文或下载许可。两端共享失败语义，各自适配宿主的加载和清理能力。

## 验收

| 编号 | 操作与预期 |
|---|---|
| A01 正常流转 | 导入一个文档版本，检查扫描报告并审核。批准前无法安装，批准后可绑定。记录来源、审核人和摘要 |
| A02 失败与阻断 | 模拟 Scanner 超时并验证暂停安装。提交含不允许文件类型的测试包，确认强制阻断无法被审核通过 |
| A03 更新和权限 | 修改已批准内容，验证新版本回到待扫描。使用只读账号和隔离空间节点尝试审批或下载，服务端拒绝 |
| A04 下载校验 | 用 Mock 节点领取任务并下载绑定版本，校验摘要。换成未绑定节点或旧租约后拒绝；篡改测试响应后插件拒绝启用 |
| A05 撤销 | 撤销版本，验证在线节点停止加载、离线节点重连后清理、已下载版本无法用于新任务 |
| A06 宿主联调 | P3 的 DSH 和 OpenCode 插件分别下载、验证并加载同一受控文档版本，保存宿主版本、任务 ID 与摘要证据 |
| A07 审核页面 | 使用提交人和审核员走一遍确认流程。并行处理同一项时只接受符合当前状态的决定；阻断项没有批准入口 |
| A08 下载失败 | DSH 与 OpenCode 分别验证限流、授权撤销、摘要不符及宿主加载异常。回报一致的失败阶段，必需技能失败时宿主不启动任务 |
| A09 撤销竞态 | 在内容已下载但尚未启用时撤销版本，启用前复核应拒绝。验证在线缓存清理、离线重连核对以及任务状态 |
